# Lake Water

An iOS app for collecting and reviewing water-quality measurements from a lake.

## Current Skeleton

- SwiftUI app entry point
- Measurement model for temperature, pH, dissolved oxygen, and notes
- In-memory store protocol for future persistence or sync
- Basic measurement list screen

Open the Swift files in Xcode and create an iOS App project using the
`LakeWater` product name. The source files are organized so they can be added
to that project directly.
